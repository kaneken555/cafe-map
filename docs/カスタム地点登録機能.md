# カスタム地点登録機能 仕様書

## 実装状況

✅ **実装完了** (2025-11-30)

すべての基本機能が実装済みです。以下の機能が利用可能です:
- カスタム地点の登録・表示・削除
- Speed Dial FABからのアクセス
- マップ上でのアイコン表示（種別ごとに異なるアイコン）
- 画像アップロード対応
- マップとの関連付け

## 1. 機能の目的・概要

カフェマップアプリケーションにおいて、ユーザーが**カフェ以外の独自の地点**をマップ上に登録できる機能。Google Places APIに依存せず、ユーザーが自由に地点を追加・管理できるようにする。

### 主な機能

- **地点登録**: ユーザーがマップ上の任意の位置にカスタム地点を登録
- **情報管理**: 地点名、種類、メモ、画像などの情報を保存
- **マップ連携**: 登録した地点を複数のマイマップに追加可能
- **UIアクセス**: Speed Dial FABから「カスタム地点を登録」を選択して登録フォームにアクセス

### 想定される用途

- 写真撮影スポット
- 待ち合わせ場所
- 景色の良い場所
- 記念碑・モニュメント
- その他、ユーザー独自の地点

### 設計思想

**既存機能との違い:**
- カフェ: Google Places APIから取得した公式データ
- カスタム地点: ユーザーが独自に登録・管理するデータ

**データ管理:**
- カフェとは異なる新しいモデル「CustomPlace」を作成
- ユーザーごとに**所有権を明確に管理**
- マップとの関連は「CustomPlaceMapRelation」で管理

## 2. データモデル

### 2-1. CustomPlace（カスタム地点）

#### モデル定義

```python
class CustomPlace(models.Model):
    """ユーザーが独自に登録する地点"""

    # 基本情報
    owner = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name='custom_places'
    )
    name = models.CharField(max_length=100)

    # 位置情報
    latitude = models.FloatField(
        validators=[MinValueValidator(-90), MaxValueValidator(90)]
    )
    longitude = models.FloatField(
        validators=[MinValueValidator(-180), MaxValueValidator(180)]
    )

    # 追加情報
    image = models.ImageField(
        upload_to='custom_places/',
        null=True,
        blank=True
    )
    place_type = models.CharField(
        max_length=50,
        null=True,
        blank=True,
        choices=[
            ('photo_spot', '写真スポット'),
            ('meeting_point', '待ち合わせ場所'),
            ('viewpoint', '景色の良い場所'),
            ('memorial', '記念碑・モニュメント'),
            ('other', 'その他'),
        ]
    )
    memo = models.TextField(null=True, blank=True)

    # タイムスタンプ
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'custom_place'
        ordering = ['-created_at']
        indexes = [
            models.Index(fields=['owner', '-created_at']),
            models.Index(fields=['latitude', 'longitude']),
        ]
```

**フィールド詳細:**

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `owner` | FK(User) | ○ | 登録者 |
| `name` | varchar(100) | ○ | 地点名 |
| `latitude` | float | ○ | 緯度（-90〜90） |
| `longitude` | float | ○ | 経度（-180〜180） |
| `image` | ImageField | × | 画像（5MB以下） |
| `place_type` | varchar(50) | × | 地点種別 |
| `memo` | text | × | メモ・説明 |
| `created_at` | datetime | auto | 作成日時 |
| `updated_at` | datetime | auto | 更新日時 |

### 2-2. CustomPlaceMapRelation（マップとの関連）

#### モデル定義

```python
class CustomPlaceMapRelation(models.Model):
    """カスタム地点とマップの関連"""

    map = models.ForeignKey(
        Map,
        on_delete=models.CASCADE,
        related_name='custom_place_relations'
    )
    custom_place = models.ForeignKey(
        CustomPlace,
        on_delete=models.CASCADE,
        related_name='map_relations'
    )

    # 表示設定
    is_visible = models.BooleanField(default=True)

    # タイムスタンプ
    created_at = models.DateTimeField(auto_now_add=True)

    class Meta:
        db_table = 'custom_place_map_relation'
        unique_together = [['map', 'custom_place']]
        indexes = [
            models.Index(fields=['map', 'is_visible']),
        ]
```

**設計ポイント:**
- 既存の `CafeMapRelation` と同様の構造
- 1つのカスタム地点を複数マップで共有可能
- `is_visible` で個別マップでの表示ON/OFF制御

## 3. UI/UX設計

### 登録フロー

#### パターン1: マップをクリックして登録

```
1. マップ上の任意の地点をクリック or 長押し
   ↓
2. コンテキストメニューが表示
   → 「この場所にカスタム地点を追加」
   ↓
3. カスタム地点登録フォームが表示
   - 名前: 自動で「新しい地点」
   - 座標: クリックした位置を自動入力
   - その他: 空欄
   ↓
4. 必要情報を入力
   ↓
5. API呼び出し → カスタム地点作成 + マップへ関連付け
   ↓
6. 完了
→ マップに地点が表示
```

#### パターン2: Speed Dial FABから登録（推奨）

```
1. 画面右下の＋FABをクリック
   ↓
2. メニューが展開され、2つの選択肢が表示される
   - 🗺️ 新しいマップを作成
   - 📍 カスタム地点を登録
   ↓
3. 「📍 カスタム地点を登録」を選択
   ↓
4. カスタム地点登録フォーム（モーダル）が表示
   - 名前: 入力必須
   - 緯度・経度: 地図選択 or 手動入力
   - 画像、種別、メモなどを入力
   ↓
5. 保存ボタン → 確認
   ↓
6. API呼び出し → カスタム地点作成 + マップへ関連付け
   ↓
7. 完了
→ マップに地点が表示
```

**メリット:**
- 明確な操作フロー（ユーザーが迷わない）
- マップ作成とカスタム地点登録を統合された「追加系アクション」として提供
- 拡張性が高い（将来的に他の追加機能も統合可能）

#### パターン3: 座標を直接入力して登録

```
1. 地図コンテキストメニュー / カスタム地点追加メニューを選択
   ↓
2. カスタム地点登録フォームが表示
   - 名前: 入力必須
   - 緯度・経度: 手動入力 or 地図選択
   ↓
3. 保存ボタン → 確認
   ↓
4. 完了
→ マップに地点が表示
```

```
POST /api/v1/custom-places/
```

## 5. バリデーション

### フィールドレベルのバリデーション

#### 名前
- **必須項目**
- **最大100文字**
- **空白のみ不可**

#### 緯度
- **必須項目**
- **数値型**
- **-90 ≤ latitude ≤ 90**

#### 経度
- **必須項目**
- **数値型**
- **-180 ≤ longitude ≤ 180**

#### 画像
- **ファイル形式: jpeg, jpg, png のみ**
- **ファイルサイズ: 最大5MB**
- **URLも許可**: 有効なURL

#### 種別（place_type）
- **許可値**: `photo_spot`, `meeting_point`, `viewpoint`, `memorial`, `other`
- **未選択も許可**

#### メモ
- **最大500文字**
- **任意項目**

```python
class CustomPlaceSerializer(serializers.ModelSerializer):
    """カスタム地点シリアライザ"""

    def validate_name(self, value):
        if not value or not value.strip():
            raise serializers.ValidationError("名前は必須です")
        if len(value) > 100:
            raise serializers.ValidationError("名前は100文字以内で入力してください")
        return value.strip()

    def validate_latitude(self, value):
        if value < -90 or value > 90:
            raise serializers.ValidationError("緯度は-90から90の範囲で入力してください")
        return value

    def validate_longitude(self, value):
        if value < -180 or value > 180:
            raise serializers.ValidationError("経度は-180から180の範囲で入力してください")
        return value

    def validate_image(self, value):
        if value:
            # ファイルサイズ検証
            if value.size > 5 * 1024 * 1024:  # 5MB
                raise serializers.ValidationError("画像のサイズは5MB以下にしてください")

            # ファイル形式検証
            allowed_extensions = ['jpg', 'jpeg', 'png']
            ext = value.name.split('.')[-1].lower()
            if ext not in allowed_extensions:
                raise serializers.ValidationError("画像はjpeg, jpg, pngのいずれかで選択してください")

        return value

    def validate_memo(self, value):
        if value and len(value) > 500:
            raise serializers.ValidationError("メモは500文字以内で入力してください")
        return value
```

```python
from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated
from .models import CustomPlace, CustomPlaceMapRelation
from .serializers import CustomPlaceSerializer

class CustomPlaceViewSet(viewsets.ModelViewSet):
    """カスタム地点 ViewSet"""

    permission_classes = [IsAuthenticated]
    serializer_class = CustomPlaceSerializer

    def get_queryset(self):
        # 自分が作成したカスタム地点のみ取得
        return CustomPlace.objects.filter(owner=self.request.user)

    def perform_create(self, serializer):
        # 所有者を自動設定
        custom_place = serializer.save(owner=self.request.user)

        # map_ids が指定されていればマップに関連付け
        map_ids = self.request.data.get('map_ids', [])
        for map_id in map_ids:
            try:
                map_obj = Map.objects.get(id=map_id)
                # マップへのアクセス権限を確認
                if MapUserRelation.objects.filter(
                    map=map_obj,
                    user=self.request.user
                ).exists():
                    CustomPlaceMapRelation.objects.create(
                        map=map_obj,
                        custom_place=custom_place
                    )
            except Map.DoesNotExist:
                pass

    def perform_update(self, serializer):
        # 所有者チェックは get_queryset でフィルタ済み
        serializer.save()

    def perform_destroy(self, instance):
        # 所有者チェックは get_queryset でフィルタ済み
        instance.delete()

    @action(detail=False, methods=['get'])
    def by_map(self, request, map_id=None):
        """マップ内のカスタム地点取得"""
        try:
            map_obj = Map.objects.get(id=map_id)

            # マップへのアクセス権限を確認
            if not MapUserRelation.objects.filter(
                map=map_obj,
                user=request.user
            ).exists():
                return Response(
                    {"error": "このマップへのアクセス権限がありません"},
                    status=status.HTTP_403_FORBIDDEN
                )

            # マップに関連するカスタム地点を取得
            relations = CustomPlaceMapRelation.objects.filter(
                map=map_obj
            ).select_related('custom_place')

            custom_places = [rel.custom_place for rel in relations]
            serializer = self.get_serializer(custom_places, many=True)

            return Response({
                'map': {
                    'id': map_obj.id,
                    'name': map_obj.name
                },
                'custom_places': serializer.data
            })

        except Map.DoesNotExist:
            return Response(
                {"error": "マップが見つかりません"},
                status=status.HTTP_404_NOT_FOUND
            )
```

```typescript
import { API_BASE_PATH } from "../constants/api";

export interface CustomPlace {
  id: number;
  owner: {
    id: number;
    name: string;
  };
  name: string;
  latitude: number;
  longitude: number;
  image_url?: string;
  place_type?: string;
  place_type_display?: string;
  memo?: string;
  created_at: string;
  updated_at: string;
  maps?: {
    id: number;
    name: string;
    is_visible: boolean;
  }[];
}

export interface CreateCustomPlaceRequest {
  name: string;
  latitude: number;
  longitude: number;
  image?: File | null;
  place_type?: string;
  memo?: string;
  map_ids?: number[];
}

/**
 * CSRFトークン取得
 */
const getCsrfToken = async (): Promise<string> => {
  const response = await fetch(`${API_BASE_PATH}/csrf/`, {
    credentials: "include",
  });
  const data = await response.json();
  return data.csrfToken;
};

/**
 * カスタム地点を作成
 */
export const createCustomPlace = async (
  data: CreateCustomPlaceRequest
): Promise<CustomPlace> => {
  const csrfToken = await getCsrfToken();

  const formData = new FormData();
  formData.append('name', data.name);
  formData.append('latitude', data.latitude.toString());
  formData.append('longitude', data.longitude.toString());

  if (data.image) {
    formData.append('image', data.image);
  }
  if (data.place_type) {
    formData.append('place_type', data.place_type);
  }
  if (data.memo) {
    formData.append('memo', data.memo);
  }
  if (data.map_ids) {
    formData.append('map_ids', JSON.stringify(data.map_ids));
  }

  const response = await fetch(`${API_BASE_PATH}/custom-places/`, {
    method: 'POST',
    credentials: 'include',
    headers: {
      'X-CSRFToken': csrfToken,
    },
    body: formData,
  });

  if (!response.ok) {
    const errorData = await response.json().catch(() => ({}));
    throw new Error(errorData.error || 'カスタム地点の作成に失敗しました');
  }

  return response.json();
};

/**
 * カスタム地点一覧を取得
 */
export const getCustomPlaces = async (): Promise<{
  count: number;
  results: CustomPlace[];
}> => {
  const response = await fetch(`${API_BASE_PATH}/custom-places/`, {
    method: 'GET',
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
    },
  });

  if (!response.ok) {
    throw new Error('カスタム地点の取得に失敗しました');
  }

  return response.json();
};

/**
 * マップ内のカスタム地点を取得
 */
export const getCustomPlacesByMap = async (mapId: number): Promise<{
  map: { id: number; name: string };
  custom_places: CustomPlace[];
}> => {
  const response = await fetch(
    `${API_BASE_PATH}/maps/${mapId}/custom-places/`,
    {
      method: 'GET',
      credentials: 'include',
      headers: {
        'Content-Type': 'application/json',
      },
    }
  );

  if (!response.ok) {
    throw new Error('カスタム地点の取得に失敗しました');
  }

  return response.json();
};

/**
 * カスタム地点を更新
 */
export const updateCustomPlace = async (
  id: number,
  data: Partial<CreateCustomPlaceRequest>
): Promise<CustomPlace> => {
  const csrfToken = await getCsrfToken();

  const response = await fetch(`${API_BASE_PATH}/custom-places/${id}/`, {
    method: 'PUT',
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
      'X-CSRFToken': csrfToken,
    },
    body: JSON.stringify(data),
  });

  if (!response.ok) {
    const errorData = await response.json().catch(() => ({}));
    throw new Error(errorData.error || 'カスタム地点の更新に失敗しました');
  }

  return response.json();
};

/**
 * カスタム地点を削除
 */
export const deleteCustomPlace = async (id: number): Promise<void> => {
  const csrfToken = await getCsrfToken();

  const response = await fetch(`${API_BASE_PATH}/custom-places/${id}/`, {
    method: 'DELETE',
    credentials: 'include',
    headers: {
      'X-CSRFToken': csrfToken,
    },
  });

  if (!response.ok) {
    throw new Error('カスタム地点の削除に失敗しました');
  }
};
```

- `PUT /api/v1/custom-places/{id}/` - カスタム地点更新
- `DELETE /api/v1/custom-places/{id}/` - カスタム地点削除
- `GET /api/v1/custom-places/by-map/{map_id}/` - マップ内のカスタム地点取得

## 12. 補足事項

### セキュリティ対策

1. **権限チェック:**
   - カスタム地点の作成・削除は所有者のみ可能
   - マップへの関連付けはマップへのアクセス権限が必要

2. **画像アップロード:**
   - ファイルサイズ上限（5MB）
   - 許可する拡張子の制限（jpeg, png）
   - XSS対策: ファイル名のサニタイズ

3. **位置情報:**
   - 緯度・経度の妥当性チェック
   - 不正な座標値の排除

### パフォーマンス対策

1. **データベースインデックス:**
   - `owner_id` + `created_at` のインデックス作成
   - `latitude` + `longitude` のインデックス作成（将来的な範囲検索用）

2. **画像最適化:**
   - アップロード時にサムネイル生成
   - 圧縮処理の実施

3. **キャッシュ戦略:**
   - マップ別の地点一覧をキャッシュ
   - Redis でキャッシュ管理（将来的に）
