# チャット機能仕様書

## 📋 概要

カフェマップアプリケーションにAIチャット機能を統合。ユーザーがマップ上でカフェ検索や情報取得をチャット形式で行えるようにする。

### 認証

すべてのエンドポイントは `IsAuthenticated` パーミッションが必要。

- **認証方式:** Session Authentication
- **CSRF保護:** X-CSRFToken ヘッダーが必要（POST/DELETE）

### フロントエンド実装（chatService.ts）

```typescript
// CSRF トークン取得
const getCsrfToken = async (): Promise<string> => {
  const response = await fetch(`${API_BASE_PATH}/csrf/`, {
    credentials: "include",
  });
  const data = await response.json();
  return data.csrfToken;
};

// セッション作成
export const createChatSession = async (data: {
  context_type?: string;
  context_data?: any;
  map_id?: number;
}): Promise<ChatSession> => {
  const csrfToken = await getCsrfToken();
  const response = await fetch(`${API_BASE_PATH}/chat/sessions/`, {
    method: 'POST',
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
      'X-CSRFToken': csrfToken,
    },
    body: JSON.stringify(data),
  });
  return response.json();
};

// メッセージ送信
export const sendChatMessage = async (
  data: SendMessageRequest
): Promise<SendMessageResponse> => {
  const csrfToken = await getCsrfToken();
  const response = await fetch(`${API_BASE_PATH}/chat/messages/`, {
    method: 'POST',
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
      'X-CSRFToken': csrfToken,
    },
    body: JSON.stringify(data),
  });
  return response.json();
};
```

## 🎯 z-index階層

```
z-60: FABボタン (ChatFAB, マップ作成FAB) - 最前面
z-50: モーダル/パネル (ChatPanel, CafeDetailPanel, MyCafeListPanel, SearchResultPanel)
z-45: 背景オーバーレイ (パネル用)
z-40: Footer (モバイル版のみ)
z-10: マップコントロール、検索バー
z-0:  マップ本体
```

**設計原則:**
1. ユーザー操作要素は最前面 - FABボタン (z-60)
2. コンテンツはその次 - モーダル/パネル (z-50)
3. ナビゲーションはコンテンツの下 - Footer (z-40)
4. 背景要素はさらに下 - オーバーレイ (z-45)
5. マップコントロールは背景層 (z-10)

## 📱 モバイル版の特別な考慮事項

### 複数パネルの重なり

**潜在的な問題:**
- CafeDetailPanel と ChatPanel は両方とも `z-40` で `bottom-0`
- 両方同時に開くと重なる可能性あり

**現状の対応:**
- 通常のユースケースでは両方同時に開くことは少ない
- UIとしては片方を閉じてから他方を開く操作を想定

**今後の改善案:**
- 一方が開いたら他方を自動的に閉じるロジックを追加
- または z-index を動的に調整

### Footer との共存

**FooterActions:** `bottom-0`（モバイル版のみ表示）

**FABボタン配置:**
- Footerの高さを考慮して `bottom-20`（80px）からスタート
- PC版では Footer がないため `md:bottom-6`

## 🚀 使用方法

### 基本操作

1. **チャットを開く:** 右下のチャットFABをクリック/タップ
2. **メッセージを送信:** 入力欄にテキストを入力して送信ボタンまたはEnterキー

4. **モバイル版でパネルを拡張:** ハンドルバーをタップ（50vh ↔ 90vh）

- **状態管理:** React useState（将来的にContextや外部ストアも検討）
- **HTTP通信:** Fetch API

### バックエンド
- **Webフレームワーク:** Django 5.1.7
- **REST API:** Django REST Framework
- **データベース:** PostgreSQL
- **認証:** Session Authentication + CSRF Protection
- **ORM:** Django ORM
- **シリアライザ:** DRF Serializers

### インフラ
- **開発環境:** Docker + Docker Compose
- **デプロイ:** AWS (EC2)
- **Webサーバー:** Nginx
- **WSGIサーバー:** Gunicorn

### 設定
- **CSRF保護:** X-CSRFToken ヘッダー
- **CORS:** 許可済み（credentials: include）
- **セッション:** Cookie-based（SameSite=None, Secure=True）
