# チャット機能仕様書

## 📋 概要

カフェマップアプリケーションにAIチャット機能を統合。ユーザーがマップ上でカフェ検索や情報取得をチャット形式で行えるようにする。

## 🎨 UI仕様

### PC版

#### レイアウト
```
┌─────────────────────────────────────────────────────┐
│                    Header                           │
├──────────────────────────┬──────────────────────────┤
│                          │                          │
│                          │                          │
│      Map (60-70%)        │   Chat Panel (30-40%)    │
│                          │                          │
│                          │                          │
│                    [+][💬] ← FABボタン               │
└────────────────────────┴──────────────────────────┘
```

#### 詳細仕様

**チャットパネル:**
- 位置: 画面右側
- 幅: `450px`（最大 `40vw`）
- 高さ: `calc(100vh - 4rem)`（Headerを除く全画面）
- アニメーション: 右からスライドイン/アウト
- 背景: 白（`bg-white`）、影付き（`shadow-lg`）
- z-index: `40`

**チャットFAB（Floating Action Button）:**
- 位置: 画面右下（`bottom-6 right-6`）
- サイズ: `56px × 56px`（`w-14 h-14`）
- アイコン: MessageCircle（lucide-react）
- カラー:
  - 閉じている時: 青（`bg-blue-600`）
  - 開いている時: グレー（`bg-gray-600`）
- z-index: `50`
- ホバー効果: スケールアップ（`hover:scale-110`）

**マップ作成FAB:**
- 位置: チャットFABの左側（`bottom-6 right-24`）
- サイズ: `56px × 56px`
- カラー: 黄色（`bg-[#FFC800]`）
- z-index: `10`

#### 詳細仕様

**BottomSheet:**

- シート本体: z-index: `40`

**FABボタン配置（縦並び）:**
- マップ作成FAB: `bottom-136px right-6`（上側）
- チャットFAB: `bottom-20 right-6`（下側）
- 両方とも Footerを避けるため `bottom-20` からスタート

## 🎯 z-index階層

```
z-60: FABボタン (ChatFAB, マップ作成FAB) - 最前面
z-50: モーダル/パネル (ChatPanel, CafeDetailPanel, MyCafeListPanel, SearchResultPanel)
z-45: 背景オーバーレイ (パネル用)
z-40: Footer (モバイル版のみ)
z-10: マップコントロール、検索バー
z-0:  マップ本体
```

**設計原則:**
1. ユーザー操作要素は最前面 - FABボタン (z-60)
2. コンテンツはその次 - モーダル/パネル (z-50)
3. ナビゲーションはコンテンツの下 - Footer (z-40)
4. 背景要素はさらに下 - オーバーレイ (z-45)
5. マップコントロールは背景層 (z-10)

## 📱 モバイル版の特別な考慮事項

### 複数パネルの重なり

**潜在的な問題:**
- CafeDetailPanel と ChatPanel は両方とも `z-40` で `bottom-0`
- 両方同時に開くと重なる可能性あり

**現状の対応:**
- 通常のユースケースでは両方同時に開くことは少ない
- UIとしては片方を閉じてから他方を開く操作を想定

**今後の改善案:**
- 一方が開いたら他方を自動的に閉じるロジックを追加
- または z-index を動的に調整

### Footer との共存

**FooterActions:** `bottom-0`（モバイル版のみ表示）

**FABボタン配置:**
- Footerの高さを考慮して `bottom-20`（80px）からスタート
- PC版では Footer がないため `md:bottom-6`

## 🚀 使用方法

### 基本操作

1. **チャットを開く:** 右下のチャットFABをクリック/タップ
2. **メッセージを送信:** 入力欄にテキストを入力して送信ボタンまたはEnterキー
3. **チャットを閉じる:**
   - PC: パネル内の×ボタン、またはFABを再クリック
   - モバイル: 背景タップ、×ボタン、またはFABを再タップ
4. **モバイル版でパネルを拡張:** ハンドルバーをタップ（50vh ↔ 90vh）

## 🐛 既知の問題・制限事項

### 1. モバイル版での複数パネル重なり

**問題:** CafeDetailPanel と ChatPanel が同時に開くと重なる

**影響:** ユーザビリティの低下

**回避策:** 現在は片方を閉じてから他方を開く運用

### 2. AI応答がモック

**問題:** 実際のAI応答が未実装

**影響:** チャット機能が限定的

**対応:** バックエンドAPIの実装待ち

### 3. メッセージ履歴が保存されない

**問題:** ページリロードでメッセージが消える

**影響:** ユーザーエクスペリエンスの低下

**対応:** LocalStorage実装を検討
